# 文档索引

根目录 [README](../README.md) 是当前版本的权威说明，包含安装、运行、接口字段、算法、点击行为、限制和故障处理。其他文档按用途分组：

| 目录 | 内容 | 是否适用于当前版本 |
| --- | --- | --- |
| [`guides/`](guides/) | 点击流程与求解器规则 | 是；与主页 README 一致 |
| [`research/`](research/) | 地图结构和牌型来源的技术分析 | 供理解实现；样本结论注明核实日期 |
| [`research/archive/`](research/archive/) | 早期抓包与逆向过程记录 | 否；仅保留历史背景，不作为当前接口依据 |
| [`samples/`](samples/) | 已核验地图的逐层牌面、操作顺序和校验记录 | 仅适用于文档标注的样本，不可用于新地图 |

Reqable 原始抓包、解码 JSON、截图、牌图模板和每次运行状态保存在本机 `captures/`、`decoded/`、`runs/` 目录，并由 `.gitignore` 排除。样本文档可引用这些本机文件；这些文件不属于仓库内容。
